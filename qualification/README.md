# qualification

Qualification evidence for the Digital Living Lifeform. Every subdirectory is
created empty in R000 and is populated by the phase that owns it.

- `fixtures/` — canonical input fixtures and their hashes.
- `replay/` — byte-identical replay evidence across the qualified device matrix.
- `fault-injection/` — process kill, storage fault, clock fault and permission fault runs.
- `longitudinal/` — long-horizon simulation runs and their canonical hashes.
- `device-matrix/` — the qualified hardware matrix and per-device results.
- `red-team/` — adversarial and exploit findings against canonical guarantees.

No qualification evidence exists yet. R000 produces a buildable foundation, not
a qualified organism.
