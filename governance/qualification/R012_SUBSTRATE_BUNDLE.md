hashes. The qualified commit is its immediate descendant, the one that
contains this file: a bundle cannot contain the hash of the commit that
contains it. The manifest hash is the durable identifier, because it is
computed from file content only and is therefore independent of commit
identity, rebases and merges. `.agent/OUTCOMES.md` records the final
qualified commit SHA.

`tools/build_qualification_bundle.py` to its qualified commit, and
verification reads that commit's blobs instead of the working tree. A
closed gate must not be breakable by a later phase editing a shared file.

## Reproducing this bundle

```
python3 tools/build_qualification_bundle.py --verify
```

To reproduce the underlying evidence rather than just verify it, run
`./gradlew build`, `./gradlew :desktop-runner:run`,
`python3 tools/generate_lookup_tables.py --check`, and the cross-target
harness `tools/qualify_r001_determinism.sh` against each target.

Unlike the R000 device evidence, the determinism evidence **is**
expected to be byte-identical on every rerun and on every target. That
is the entire claim: if `R001_EVIDENCE_DIGEST` differs between two runs
or two targets, R001 has failed.
