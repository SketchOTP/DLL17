# Decision log

Implementation decisions that are not architect directives. Architect decisions
live in the canonical Notion pages and in `.agent/RECORD.md`.

| ID | Date | Decision | Rationale |
|---|---|---|---|
| IMPL-0001 | 2026-08-12 | `core-math`, `core-crypto` and `core-state` apply only the Kotlin JVM plugin, and each carries a test asserting the Android framework is absent from its classpath. | Makes the E2E module boundary an enforced build fact rather than a convention. |
| IMPL-0002 | 2026-08-12 | `android-host` applies `com.android.application` and the Compose compiler plugin, and does not apply `org.jetbrains.kotlin.android`. | AGP 9 provides built-in Kotlin support and fails the build if the standalone plugin is applied. Frozen Kotlin 2.4.10 still governs the module. |
| IMPL-0003 | 2026-08-12 | The R000 registries are stored as versioned Markdown under `docs/architecture/registries/`. | Implementation Plan E2E mandates the registries but does not fix their location; Markdown keeps them reviewable and diffable before any code depends on them. |
| IMPL-0004 | 2026-08-12 | The root `LICENSE` was replaced with a proprietary, all-rights-reserved notice, superseding the inherited MIT grant. | Architect directive D005 resolved the recorded conflict in favour of the frozen `ProjectIdentityBuildContractV1` licensing clause. Repository visibility was explicitly left unchanged by the same directive. |
| IMPL-0005 | 2026-08-12 | The R000 qualification target is `system-images;android-37.0;google_apis;x86_64` under an x86_64 KVM-accelerated emulator. | It is the only available system image matching the frozen `compileSdk`/`targetSdk` 37 exactly, and the canonical determinism matrix already names the x86 Android emulator as a required target. |
| IMPL-0006 | 2026-08-12 | Resource evidence is recorded as `R000_MEASURED_BASELINE` observations only; no future production budget was assigned a number. | Directive D005 prohibits fabricating future targets. Measured observations of the empty shell are evidence; guessed ceilings would be invented constants that later qualification would have to unwind. |
| IMPL-0007 | 2026-08-13 | Canonical length prefixes are fixed 4-byte big-endian; variable-length integer encodings are prohibited. | Varint schemes admit non-minimal encodings, so the same value has more than one representation. Byte identity must be a property of the format, not of implementer discipline. |
| IMPL-0008 | 2026-08-13 | SHA-256 is implemented inside `core-crypto` rather than obtained from `java.security.MessageDigest`. | The algorithm's output is standardized but provider *resolution* is not: it differs between a desktop JDK and Android, moves as Conscrypt evolves, and can be reordered at runtime. Verified against FIPS 180-4 vectors and differentially against the platform provider on every target. |
| IMPL-0009 | 2026-08-13 | The PRNG is counter-based SplitMix64 (`PRNG_SPLITMIX64_V1`) with a 16-byte serialized state. | Smallest durable footprint of the candidates, integer-only with no table, public-domain reference implementation, and counter-based so a recovered substream cannot drift. |
| IMPL-0010 | 2026-08-13 | Fixed-point rounding is half away from zero on every rescaling operation. | Truncation toward zero and floor are both asymmetric about zero and inject a systematic drift into repeated decay over an organism lifetime. Banker's rounding removes bias but adds a tie-parity test that is easy to implement inconsistently. |
| IMPL-0011 | 2026-08-13 | 128-bit intermediates use explicit 32-bit limbs; `Math.multiplyHigh` is prohibited and `BigInteger` is test-only. | `Math.multiplyHigh` reached Android only at API 31 while the frozen `minSdk` is 29, so it would compile against `compileSdk` 37 and throw `NoSuchMethodError` on a supported device — a failure no desktop test would catch. |
| IMPL-0012 | 2026-08-13 | Canonical identifiers are restricted to an ASCII subset and canonical state carries no natural-language text. | Removes Unicode normalization, locale-sensitive case folding and ICU collation from the canonical path entirely. Android's Unicode version advances independently of the JDK's, so this is eliminated by policy rather than tested around. |
| IMPL-0013 | 2026-08-13 | R001 determinism is qualified through an Android instrumented test rather than through the shell UI, leaving the R000 shell untouched. | Determinism is a property of ART executing the canonical core, not of Compose. Changing the shell would also have invalidated the R000 launch harness and its closed-gate evidence. |
| IMPL-0014 | 2026-08-13 | The qualification bundle tool now pins a closed phase to its qualified commit and verifies that phase from `git show`, instead of from the working tree. | A defect found during D006: R000's bundle verified against the working tree, so any later phase editing a shared build file or registry would have broken a gate that had already passed. Evidence of a past qualification must not depend on the present. |
| IMPL-0015 | 2026-08-13 | The durable medium for R001 is an in-process append-only byte log, not a database. | R001 owns the durability *contract* — append-only ordering, acknowledgement, `reduce == replay`. Persistence *semantics* are R002's `ContinuityDurabilityContractV1`, and implementing them here would pre-empt a later phase's decisions. |
